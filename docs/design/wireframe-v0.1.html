AriaNg-Next 控制面板
结构线框 v0.1

保留 AriaNg 的内核逻辑与操作心智（多主机、增量轮询、任务分组、拖拽调序、全局选项、通知）， 重做信息层级与交互外观，并把「外观」从固定皮肤升级为可编程的令牌 + 自定义 CSS； 同时针对 aria2-next 新增的 ED2K / HLS / DASH 能力与运行时诊断数据预留独立信息位。

本轮：结构线框 主题：亮 / 暗 / 毛玻璃（可选第三主题） 技术栈：待定稿后选型 下一轮：高保真原型
一句话方向

不是给 AriaNg 换皮，而是把「下载状态」重新排成信息的第一层

AriaNg 的问题不在功能，而在所有东西长得一样：状态、进度、速度、协议、错误被平铺成一张密表， 眼睛找不到「现在该看什么」。AriaNg-Next 的骨架是三段式——顶部常驻全局状态（连接 / 总速 / 批量操作）、 中部任务流（状态分段 + 可切表格/卡片）、右侧详情抽屉（任务细节不离开列表）。 外观全部由令牌驱动，因此「换主题」和「写自定义 CSS」是同一套机制的两个入口。

保留：AriaNg 全部核心操作路径 重做：信息层级 / 视觉语言 / 响应式 新增：CSS 引擎 + 能力探测 + 诊断面板

设计原则与信息架构

三条原则决定所有后续页面的取舍；下面这张图是全站唯一的骨架，其余页面都是它在某个状态下的展开。

1

状态优先

连接状态、整体速度、ETA、失败数永远占据视觉第一层；协议徽章、路径、tracker 降到第二层，装饰降到第三层。

2

一处可改

所有外观走同一套 CSS 变量令牌。换主题 = 换令牌集，写自定义 CSS = 在令牌之上叠加规则，不存在第二套机制。

3

诚实的数据

未连接 / 协议不支持 / 能力探测失败 / 任务卡死，都要有显式状态位，不允许用空白或骨架屏伪装。

自定义 CSS 的分层与生效规则

这是整套外观体系的技术底座，也是「可换肤」与「可编程」统一的关键。

用户 CSS 层custom.css · 最高优先级
最后注入、可覆盖前面所有规则。默认作用域限定在 .an-app 容器内，只影响面板自身；可显式切换为「全局生效」以修改 body / 滚动条 / 字体等。
组件层an-*.css
按语义命名的组件样式（.an-task-row、.an-drawer、.an-stat），选择器稳定且带版本语义，是用户 CSS 的主要作用对象。刻意不使用工具类框架，否则自定义 CSS 难以书写。
令牌层--an-*
全部颜色、间距、圆角、字号、层级、动效都以 CSS 变量表达。主题切换 = 替换令牌集；可视化调色器 = 直接改写变量值并回写为可读的 CSS 片段。
基础层reset + element defaults
统一重置与原生元素默认值（滚动条、表单、焦点环）。暗色主题通过令牌换值实现，而非反色滤镜。
✓
热更新：编辑即预览，不需要刷新页面；解析错误定位到行号并保留上一份可用样式。
✓
可撤销：一键重置 / 本地保存多个版本并切换 / 导出为 .css 文件。
✓
可移植：自定义 CSS 随「配置导出」一起走，多台机器/多人共享同一套外观。
✓
可降级：毛玻璃主题在低性能设备上自动退化为半透明纯色，保证可读性与帧率。

主题体系 · 三套预设

三套主题共用同一份结构与同一组令牌，只替换令牌集。毛玻璃为可选增强，不作为默认。

Light
默认 · 白天 / 文档场景
画布 #FAFAFB · 卡片纯白 · 阴影极弱 · 1px 分割线
Dark
默认 · 夜间 / NAS 常驻大屏

Glass
可选 · 半透明 / 桌面环境

1
令牌命名统一前缀 --an-*，避免与用户自定义 CSS 冲突，也让用户在 DevTools 里一眼认出可改项。
2
主题切换不重建 DOM：只替换根元素上的令牌 class，动画与状态全部保留。
3
毛玻璃作为令牌集 + 少量组件规则：大部分毛玻璃效果由 --an-surface-blur、--an-surface-alpha 两个变量表达，用户改 CSS 也能自行调。
4
跟随系统：Light / Dark 可设自动跟随系统；Glass 需手动开启（因为它依赖背景图）。
